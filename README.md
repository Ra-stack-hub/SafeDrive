# SafeDrive - Driving Behavior Analysis App

## Project Overview

SafeDrive is a mobile application developed using React Native and Expo that analyzes driving behavior using smartphone sensors. The application monitors sensor data in real time and detects unsafe driving events such as harsh braking, harsh acceleration, sharp turns, and phone handling while driving.

The system calculates a driving safety score based on detected events and provides a dashboard showing driving statistics, event history, and safety ratings.

## Sensors Used

### 1. Accelerometer

Used to detect sudden changes in acceleration and braking.

### 2. Gyroscope

Used to detect rotational movements, sharp turns, and aggressive steering behavior.

### 3. Device Motion

Used to monitor overall device orientation and motion data.

### 4. Magnetometer (Optional)

Not implemented in the current version.

---

## Event Detection Strategy

### Harsh Braking

Detected when the acceleration force falls below the defined threshold.

### Harsh Acceleration

Detected when the acceleration force exceeds the defined threshold.

### Sharp Turn

Detected when gyroscope rotation values indicate rapid turning motion.

### Phone Handling

Detected when excessive device rotation suggests the driver is handling the phone while driving.

### Event Timeline

Each detected event is recorded with a timestamp and displayed in the dashboard.

---

## Threshold Values Chosen

| Event              | Threshold    |
| ------------------ | ------------ |
| Harsh Braking      | Force < 0.4  |
| Harsh Acceleration | Force > 1.8  |
| Sharp Turn         | Rotation > 4 |
| Phone Handling     | Rotation > 7 |

These values were selected experimentally to reduce false detections during normal driving conditions.

---

## Driving Score Calculation Logic

Initial Driving Score = 100

Penalty Rules:

| Event              | Score Deduction |
| ------------------ | --------------- |
| Harsh Braking      | -5              |
| Harsh Acceleration | -5              |
| Sharp Turn         | -3              |
| Phone Handling     | -10             |

Formula:

Final Score = 100 − Event Penalties

Safety Rating:

| Score Range | Rating    |
| ----------- | --------- |
| 90 - 100    | Excellent |
| 75 - 89     | Good      |
| 60 - 74     | Average   |
| 40 - 59     | Risky     |
| 0 - 39      | Dangerous |

## How To Run Locally

### Clone Repository

```bash
git clone https://github.com/your-username/SafeDrive.git
cd SafeDrive
```

### Install Dependencies

```bash
npm install
```

### Start Application

```bash
npx expo start
```

### Run On Device

1. Install Expo Go on Android.
2. Connect phone and computer to the same network.
3. Scan the QR code generated by Expo.
4. Start testing driving sessions.

---

## Assumptions Made

* The smartphone remains mounted in a stable position during driving.
* Sensor readings are available and supported by the device.
* Threshold values are approximate and may vary depending on the device.
* Phone handling events indicate possible driver distraction.
* The application is designed for educational and demonstration purposes.
